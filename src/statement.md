# Banking Management System

## Problem Statement

Basic banking operations require maintaining account information and performing transactions accurately. This project provides a simple Java-based system to demonstrate how account data and banking operations can be represented and managed using object-oriented programming.

## Scope of the Project

The system allows users to create and manage bank accounts and perform basic banking operations such as deposits, withdrawals, fund transfers, balance checking, account details viewing, and transaction history.

The project is designed as a command-line Java application for educational purposes.

## Target Users

- Students learning Java and Object-Oriented Programming
- Users who want to understand basic banking operations through a simple command-line application
- Academic evaluators reviewing Java programming concepts

## High-Level Features

- Create a new bank account
- View account details
- Deposit money
- Withdraw money
- Transfer money between accounts
- Check account balance
- View transaction history
- View all accounts
- Validate user input
- Handle invalid banking operations
